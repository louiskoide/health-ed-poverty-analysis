# health-ed-poverty-analysis
This project examines the relationship between poverty rates and emergency department (ED) performance scores across U.S. states using publicly available data from the Centers for Medicare and Medicaid Services (CMC) and the U.S. Census Bureau American Community Survey. States were grouped into higher- and lower- poverty categories based on the median poverty rate in the sample. Hospital-level ED performance scores were aggregated to the state level and merged with state-level poverty estimates to compare trends across groups. This analysis is exploratory and limited by data availablity and aggregation at the state level.

## Data Sources
- Centers for Medicare & Medicaid Services (CMS)
- U.S. Census Bureau (ACS)

## Methods
- Data cleaning and aggregation
- Merging state-level datasets
- Exploratory statistical analysis

## Limitations
Results are exploratory and limited by state-level aggregation.
